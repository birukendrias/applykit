# applykit

Paste a job description and a short CV blurb. Get an outreach draft and a tailored bullet list.

v0.1 is deterministic (no API key). Later: optional LLM + PDF export + Telegram.

## Run

```bash
python3 -m http.server 5175
```

Or open `index.html` directly.

## CLI

```bash
python3 applykit.py --jd job.txt --cv cv_blurb.txt
```
